DAO / Repository Pattern

Every table is reached through exactly one repository class — the DAO layer. Controllers depend on repositories (never on EF Core directly); each repository wraps AppDbContext with parameterised LINQ, so SQL injection is prevented by construction. The upgrade added 9 repositories (16 total) and one shared domain service, ChatDirectory.

DAO / Repository

structure · 16 repositories

Controllers receive repositories by constructor injection (DI). A repository exposes intention-revealing async finders/mutators and translates them to LINQ over a DbSet<T>. ChatDirectory is a thin domain service that composes several repositories to answer "who may chat with whom", reused by both ChatController and ChatHub.
